# Consensus Discriminators — five measurable separators + the template level

Use these when the four-type classification (genuine / manufactured /
groupthink / confirmation bias) is contested or high-stakes. Each
discriminator is checkable against the texts themselves — cite instances, not
impressions.

## 1. Inferential distance

Do the agreeing sources traverse DIFFERENT reasoning chains to the shared
conclusion, or the same chain? Independent analyses show different
intermediate steps, different objections considered. Same-chain agreement is
one inference, many bylines.

## 2. Dimensionality

Genuinely independent analyses agree on the headline but differ on secondary
dimensions (magnitude, timing, mechanism, exceptions). Agreement that extends
to secondary dimensions where agreement is improbable is a coordination
signal — count the dimensions of agreement.

## 3. Lexical fingerprint

Rare-phrase overlap: idiosyncratic collocations, uncommon metaphors, identical
statistics with identical rounding in identical order. Wire-copy reuse is
transparent and doesn't count; the signal is fingerprint overlap across
outlets claiming independent editorial judgment.

## 4. Temporal granularity

Who has DETAILS before they are publicly derivable? An outlet publishing
fine-grained specifics ahead of the primary record either has a source
(name/type it) or a script. Map detail-level against the public-evidence
timeline.

## 5. Pre-positioning

Explainers, definitions, and frames published BEFORE the event that needs
them. A frame that was waiting is a frame that was prepared — check
publication dates of the interpretive furniture, not just the news items.

## The template level (where the dichotomy melts)

Individual authors can be authentically independent — no coordination, no
shared funder — and still converge, because the PRIORS they reason from were
installed upstream (education, decades of coverage, canonical
reference-points). At template level the independent/coordinated dichotomy
melts: the inference is independent; the furniture is prefabricated. Two
consequences, held together:

- **Symmetric:** every long-lived information ecosystem installs templates —
  this is not a property of one bloc (Principle P4 (counter-default)).
- **Practical:** when discriminators 1–5 clear a consensus as genuinely
  independent, ask ONE level up: independent inferences from WHICH shared
  template? Template-level convergence is real evidence about the template's
  reach, and weaker-than-it-looks evidence about the world (Principle P7
  (blindness-is-not-independence) — the human-scale version).
