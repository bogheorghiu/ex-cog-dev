# Financial Obfuscation Lens

Structures whose FUNCTION (POSIWID) is to make beneficial ownership, funding
direction, or money provenance expensive to trace. Presence of a structure is
never proof of misuse — each has legitimate uses; the lens asks what the
STACK of them achieves in this case.

## Taxonomy (check each layer; note stack depth)

- **Layered ownership:** shells, holdings, nominee directors, jurisdictions
  chosen for registry opacity — trace to warm bodies or state entities;
  record where the trace DIES and why.
- **Pass-through philanthropy:** foundations/DAFs between funder and
  recipient — donor-advised opacity, fiscal sponsorship, regranting chains.
- **Fee/royalty capture:** value moved as management fees, IP royalties,
  transfer pricing — benefit without headline ownership.
- **Related-party loops:** vendors/lenders/landlords sharing beneficiaries
  with the entity — the money circles, the books don't say so.
- **Timing structures:** pre-positioned vehicles (formed before the event
  that makes them useful — calendar test), sunset entities dissolved after
  one transaction.

## Protocol

1. Map the visible money path; 2. per hop, check the taxonomy; 3. record the
stack depth (one structure is business; five stacked is a finding); 4. state
where the trace died — an untraceable path is a FINDING about the structure,
not a verdict about intent (kernel-shell discipline: observation ≠
attribution); 5. symmetric per Principle P4 — the lens applies to
foundations and NGOs exactly as to corporations (*worked stack, fictional:
the "Meridian Civic Trust" funds an election-monitoring NGO. Layer 1 — the
Trust is a donor-advised fund at a larger sponsor, so the original donor is
donor-advised-opaque. Layer 2 — the NGO rents its office from a holding
company whose registered director is the Trust's treasurer (related-party
loop). Layer 3 — the "independent" analytics vendor it pays shares a
beneficial owner with that holding company (fee capture + loop). The trace
dies at the sponsor's jurisdiction, which publishes no grantor detail. Three
stacked structures around a civic NGO is the finding — none of it names
intent; the symmetric point is that this is the SAME trace you would run on a
defense contractor*).

## Output

Feed the ownership-chain and horizontal-source-analysis sections of the
report template; recurring entities get source-dossier entries.
