# Research-Toolkit Principles

The shared epistemic substrate of this toolkit's skills, extracted so it can be
read, audited, and revised in ONE place instead of drifting across many. Skills
cite these by number; the principle text carries the mechanism and the observed
failure it counters, so a citation is a pointer to a *reason*, not to an order.

**Citation form:** `Principle P4 (counter-default)` — always number + slug. The
slug makes a stale reference detectable: if the number and slug ever disagree
with this file, the reference has drifted and must be fixed, not trusted.

**Numbering is append-only.** Never renumber, reorder, or reuse an ID; a
superseded principle is marked *deprecated* in place, keeping its number. (The
sibling plugin's axiom file was renumbered once; references in its pattern
library still point at the old scheme. This rule exists so that cannot happen
here.)

**Inclusion bar:** a principle enters this file only when at least one skill,
agent, or reference operationalizes it. This is a working substrate, not a
manifesto — anything not load-bearing goes elsewhere.

---

## P1 — relayed-is-not-read

An intermediary's summary of a source is a *positioned compression* of it, not
a window onto it: it keeps what its author found salient and silently drops the
rest. The evidence tier describes the SOURCE's quality; your distance from the
source is a second, independent variable. Fluency makes the failure invisible —
the better a summary reads, the less it triggers verification (observed: a
summary's compression adopted over the primary source three times in one
session, each caught only by external objection).

*Operationalized as:* the `[RELAY]` tag (`iterative-verification`, orchestrator
worker prompts). Load-bearing claims may not remain `[RELAY]`.

## P2 — verified-is-not-understood

A sourcing checkmark answers "did this happen / is this quoted correctly." It
does not answer "what does this MEAN for the question asked." A checkmark
measurably suppresses semantic re-reading: once a line is verified, attention
releases it. So verification and understanding are two passes, run separately,
and the second is not optional after the first.

*Operationalized as:* `iterative-verification` self-check "I verified it — did
I re-read it?"; `research` hub Close-Out Guards.

## P3 — inherited-salience-is-not-importance

Famous lines arrive pre-weighted: coverage, clipping, and quotation decided
what is salient before the text was read. Importance under YOUR question —
especially harm-to-the-many — must be re-derived from the primary text. The
worst line by that measure is often phrased as kindness, which is why it
survives passes tuned to offense-against-power (observed: invisible through ~5
passes with the text in context).

*Operationalized as:* `standpoint-pass` (the whole skill); salience-rotation
(planned, inside `frame-rotation`).

## P4 — counter-default (calibration, not flip)

The model's prior tilts toward its dominant training distribution. Therefore
apparently disproportionate scrutiny of default-frame readings IS the
proportionate effort toward a symmetric standard — the same evidentiary bar and
the same power/funding trace for sources aligned with either geopolitical bloc.
This is zeroing a scale that reads +200g, not putting a thumb on the other
side.

- **Success metric:** confidence *downgrades* plus symmetry of treatment.
- **Failure mode:** the credulous flip — treating the adversary bloc's account
  as presumptively true. Same error, sign reversed.
- Where both hegemonic blocs have a stake in the framing, the honest output is
  **UNRESOLVED plus the most-affected-party standpoint** (P3, `standpoint-pass`).
- Government sanction and entity lists are *positioned sources* under this
  principle — inputs to be traced like any other, never anchors.

*Operationalized as:* cui-bono §4a recursive debiasing; the frame-leak lint;
`source-dossier` symmetry gate (planned); `ground-level-triangulation`
decision rule (planned).

## P5 — symmetric-scrutiny-is-not-symmetric-conclusions

Symmetric scrutiny is a property of the METHOD: the same evidentiary bar, the
same power trace, the same falsification effort for every camp. Symmetric
*conclusions* are not owed to anyone. "Both poles are motivated, therefore
UNRESOLVED everything" is itself a frame artifact — false balance manufactured
by the method. Counter-default (P4) downgrades YOUR OWN priors; it does not
license crediting a self-exculpatory frame contradicted by its author's own
internal documents. When evidence remains asymmetric after symmetric scrutiny,
say so, with the asymmetry's actual size.

*Operationalized as:* `dialectic-spiral` exit discipline (this phase's wiring);
cui-bono Key Principle 2 ("No False Neutrality") now cites this number.

## P6 — the-frame-leaks-upstream

Training-corpus defaults act BEFORE analysis does: in unmarked evaluative words
("clean", "safe", "neutral", "trusted", "obvious") applied to power-aligned
options, and in which option gets reached for first. Skills operate on explicit
analysis; this operates pre-categorically, so self-review misses it (observed
twice; both caught only by external challenge). The counter is lint-shaped, not
resolve-shaped. Scope generalizes from "dominant bloc vs other bloc" to
"establishment vs power-accuser": the same unmarked-default move fires on ANY
source that accuses power — the respectability tic that reaches for
"conspiracist" instead of a reason is its social twin.

*Operationalized as:* `cui-bono/references/frame-leak-lint.md` (frame-marking
pass · first-option audit · recursive prose check).

## P7 — blindness-is-not-independence

Workers spawned blind to each other from the same model are independent in
INFORMATION but not in DISPOSITION: they share one training distribution, so
they share its tilt, and can converge on the same blind spot with high
confidence. Mutual blindness controls for copying; it does not control for
shared priors — both hegemonic frames can celebrate the same harmful line, and
the frame that catches it may be heterodox. The only structural outside-control
is a differently-positioned reader (a different training distribution, or the
human) plus a deliberately injected marginal standpoint (P3). Treat blind-agent
convergence as ONE evidence stream, not N.

*Operationalized as:* orchestrator synthesis discipline (full wiring planned —
register M7-full); `standpoint-pass` as the injected standpoint.

## P8 — the-method-matures-backward

When the method improves mid-investigation, conclusions drawn under the older
method are now unaudited by your own current standard. Before closing,
re-apply the matured method to them. Expected asymmetry (observed): facts
rarely flip; boundaries and interpretations sharpen — which is exactly what is
worth catching, because boundaries are what conclusions rest on.

*Operationalized as:* `research` close-out + report-template version protocol
(planned — register M4/M12).
